colophon

a colophon is a document (typically found at the end of a book or publication) that describes the tools and technologies used in it's development. a colophon in web is just about the same thing.

the code

This site is hand-coded in plain HTML, CSS, and vanilla JavaScript. While coding in pure JS adds a level of complexity, it also allows for simplicity in not relying on external libraries. Pages share a header and footer via a small partials.js script to make my life easier during the yearly copyright update.

Fonts are served locally. Type is set in PP Neue Montreal ↗ by Pangram Pangram Foundry. This font is allowed to be used for free for personal use.

the hosting

Served via GitHub Pages ↗ for free. The source has lived on a public repo on GitHub since 2019 (and seen many many many evolutions). The domain is registered through Namecheap ↗. I also use Google Search Console ↗ to make sure pages and material are properly indexed within the web.

the tools

Ideations and prototype designs are made in Figma ↗. It is then coded from scratch in Visual Studio Code ↗. Version-controlled with Git, and files pushed via GitHub Desktop ↗. Any form material uses Back4App ↗ to handle submissions (contact & bug reports). Back4App is a cloud backend built on Parse.

the person

Coded & made by me, Zahra Baxi! I'm a product designer working with digital and physical interactive mediums. I've been doing web-design and web-coding since 2019 (since high school!) with both self-taught and formal education. I also am a graduate teaching assistant for web design and development @ UCD. Since this site is made with pure code, if something looks broken or you have any feedback, please let me know (you can leave a bug report by clicking on the bug icon floating on the bottom right the corner).
